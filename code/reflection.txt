The file-based app helped me to understand the difference between bytes and text. Uploaded files are in bytes, 
so I had to decode them with UTF-8 before splitting them into lines, stripping blanks, and parsing package 
descriptions. This lets me handle a file with a blank line in the middle without producing an error. The third 
app was the hardest because the same file would be processed repeatedly unless I used a button and stored the 
counters in st.session_state so they initialize once and stay the same across reruns. This assignment made the 
Streamlit easier to understand in that widgets return values, the script reruns on each interaction, and state 
must be carefully managed. My next step is to keep practicing this pattern so I can confidently build apps that 
respond to user input without breaking on unclean data structures.
